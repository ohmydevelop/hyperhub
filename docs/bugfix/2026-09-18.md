## 配置审批语义一致性

- 修复审批界面直接暴露 JSON Patch `op/path`、缺少稳定标识，导致用户难以判断配置项是新增、修改还是删除的问题。
- 每条待审请求增加独立 UUID，并展示持久化配置对象 UUID、语义动作、分类路径、对象名称和字段名称；原始 patch 降级到 `technical` 区域。
- Config TUI 与 `approve` 共享分类语义，并统一网络沙盒、动作、路由和基础配置术语。

## Help 命令按能力域归组

- 修复配置命令分散在主命令、审批和维护分组，服务生命周期命令分散在主命令与服务操作分组的问题。

## Linux Gum 非阻塞连接缺少 SOCKS 握手

- 现象：动态程序在非阻塞 socket 上收到 `EINPROGRESS` 后，Agent 已把连接目标改为本地 SOCKS 入口，但没有在连接就绪后补做 SOCKS5 握手；curl 随后直接发送 TLS ClientHello，Serve 报 `invalid SOCKS5 greeting (first bytes 0x16 0x03)`，客户端收到 `curl: (35) Recv failure: Connection reset by peer`。
- 修复：阻塞连接继续在 `connect` 返回前完成握手；非阻塞连接在首次 `send/recv/read/write` 前临时切换为阻塞模式完成三阶段 SOCKS5 握手，再恢复原 flags。握手发送、固定响应和变长 CONNECT 响应均按完整帧循环读写，并保留原始 connect errno。
- 回归：动态 C 探针同时覆盖阻塞与非阻塞 connect、poll、延迟握手和后代进程。真实 DevBoard 请求通过 HyperHub 携带占位 Authorization 返回 HTTP/2 200、`msg=success`；相同占位 Header 直接请求返回 HTTP 401 `unauthorized`，证明凭证已由 HyperHub 替换注入。
