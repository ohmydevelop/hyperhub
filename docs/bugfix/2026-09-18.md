## 配置审批语义一致性

- 修复审批界面直接暴露 JSON Patch `op/path`、缺少稳定标识，导致用户难以判断配置项是新增、修改还是删除的问题。
- 每条待审配置项增加 UUID、语义动作、分类路径、对象名称和字段名称；原始 patch 降级到 `technical` 区域。
