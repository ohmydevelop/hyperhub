# 2026-10-15

## 补齐 Hook 等价入口与状态关联

- Linux ptrace 增加 DNS `sendmmsg/recvmmsg/readv/writev` 关联，按实际发送及接收结果处理批量报文；使用 socket、resolver、transaction ID 和 question 匹配查询，避免同一 UDP socket 的多个域名串联错配。关闭 socket 时清理未完成事务，地址注解按 fd 表隔离。
- 显式建模共享 fd 表和 open file description；覆盖 `CLONE_FILES`、普通复制、`close_range(UNSHARE)` 与 exec 后分裂，避免关闭/复用 fd 后继续使用旧 socket 的非阻塞状态。
- Linux ptrace/Gum 的文件映射同时检查 Read/Write 意图，阻止通过只读 mmap 或 mprotect 可读升级绕过 Read 规则。
- 对当前无法安全保持组合语义的入口明确拒绝：Linux TCP Fast Open 的 `sendto/sendmsg/sendmmsg(MSG_FASTOPEN)` 返回 `EOPNOTSUPP`，Windows 非空首包 `ConnectEx` 返回 `WSAEOPNOTSUPP`。普通 TCP connect 与无首包 ConnectEx 继续受控执行；不放行未知 Fake-IP。
- Windows `GetAddrInfoExW` 异步入口保留 OVERLAPPED、完成通知和取消句柄，使用原生异步解析；原生完成回调在交付结果前补充域名关联；事件模式使用内部 OVERLAPPED 完成后写回状态并触发调用者原事件，不再依赖在 Windows CI 中安装失败的结果读取函数 Hook。同步完成不伪造异步回调，完成上下文不会覆盖未结束的同一请求身份。
- Agent DNS 关联统一以解析后的 IP 地址为键，避免 DNS 入口使用协议版本 `4/6`、连接入口使用平台 `AF_INET/AF_INET6` 时丢失域名。网关重定向和网络规则查找使用同一键；保留现有 ABI 参数与调用兼容性。
- 修复完整 Linux Suite 暴露的 Gum 退出码丢失：使用私有目录中按 PID 隔离的 `on_exit/_exit/_Exit` 结果作为内核状态不可得时的后备；原子写入且不跟随符号链接。缺少可观察退出码时明确报错，不返回虚构的成功状态。
- 新增独立于 Hook 命中计数的 Linux/Windows 源码回归入口，注册到 Linux 统一 Suite 和 Windows CI。Linux 探针检查目的身份、网关经过、拒绝结果、fd 状态和退出码；Windows 探针比较原生与受控的事件/回调/取消和 ConnectEx 行为。

验证进度：本机 workspace 全目标测试通过（CLI 137、Agent core 21、core 189），Linux Gum Agent 28 项测试通过；完整 Linux 统一 Suite 和最新 46 项语义回归通过，包括部分批量成功、共享/复制/unshare/exec 及非主线程 exec、四种退出方式和映射权限。Windows GNU 全目标交叉检查通过；原生 Windows 构建已通过，新增 Gum 测试暴露并修正了旧 Hook 编号上界断言，CI 原生回归正在复验。发布前核对最终 CI。未测试 macOS Hook 能力。
