
# config TUI 空闲轮询卡顿

- 现象：`hyperhub config` 界面空闲时反应迟缓，输入有明显延迟；8-19 加入进程每秒自动刷新后出现。
- 原因：主循环在 `6ff410e` 由按键驱动改为 `poll(250ms)` 后空闲时约 4 次/秒整帧重绘；`query_injected_processes` 每次刷新都新建 Tokio Runtime，并在 UI 线程执行控制面往返，刷新路径还额外调用 `serve_is_running()` 再建一次 Runtime。
- 修复：主循环改为事件驱动，空闲等待 1 秒，仅在按键、终端事件或每秒刷新后重绘；配置面请求复用 `OnceLock` 创建的单一 Tokio Runtime；刷新路径不再重复探测 Serve，离线时由查询快速失败降级。
- 验证：`cargo fmt --all -- --check` 与 `cargo test --workspace --all-targets --locked`（CLI 74、Agent 17、Core 151）通过。
