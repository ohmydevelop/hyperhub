## 加强文件映射回归与 Windows 子进程失败诊断

组合权限修复后，映射回归原先在托管目标内以 O_RDWR 打开只读拒绝文件，已在打开阶段正确被拒绝，无法再证明 mmap/mprotect 本身被拦截。改为隔离驱动预先打开虚构文件并显式传入 FD，目标验证设备、inode、大小及访问模式；逐项断言实际映射阶段的 EACCES。普通文件映射通过 volatile 读写和恢复核对，防止把未执行的内存操作计为成功。实际 ptrace/Gum 共 64 项通过，包含 36 个 FD 验证场景；完整 Suite 另行验收。

Windows 原生 CI 39921657591 的 Agent 93 项通过，三个重启目标均完成初始输出及匿名内存映射，但初始 cmd.output 仍返回 Access denied，尚未执行重启，不能声称重启验收通过。新增失败后有界诊断：真实管道及 NUL 类型、继承和空标准流的创建阶段，以及私有审计中至多 32 条白名单元数据；保留原始失败、策略和时限。未解析文件路径的拒绝事件增加句柄类型元数据，并保持调用者 Win32/WSA 错误状态。诊断不输出配置、参数或凭证，不增加未知对象豁免。

本地格式、Windows GNU Agent/CLI 编译、目标程序 Linux/Windows 链接及审计白名单和边界测试通过。GNU 编译不能代替原生 Windows 执行；v0.2.14 仍须通过新提交的完整 CI 后发布。
