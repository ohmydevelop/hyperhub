# 配置 TUI 列表输入提示

- 路由目标、网络目标、端口、文件路径、可执行文件和命令行的添加/修改弹窗会就地说明允许的值、匹配语义与输入示例。
- 路由目标明确提示支持域名、URL 路径、IP 和 CIDR；网络目标明确提示不支持 URL 路径。

# 输入光标不再挤压文本

- 删除会占用一个字符格的块状光标字符，改用终端原生细竖线光标，移动光标时输入内容不再后移。
- 光标位置按字符显示宽度计算，兼容中文和掩码输入；退出 TUI 时恢复用户的默认光标形状。

# 路由启用字段前置

- 路由详情的“启用”移到 ID 之后，不再放在审计字段后面；键盘切换与新的字段顺序保持一致。
# 后台启动错误与 Linux 交互终端

- `start` 只读取本次后台 Serve 尝试产生的日志，运行时错误不再重复打印 usage，也不会混入以前的启动记录。
- 环境变量中的 `socks://` 代理按 SOCKS5 处理，未知代理协议的错误会列出受支持方案。
- Linux `run` 在交互终端中通过内部 PTY launcher 启动实际目标，保留 Frida 根注入与 child gating，同时恢复控制终端、作业控制、窗口尺寸和有序输入输出；管道与重定向继续使用非交互路径。
- Linux 控制端点不再随 `XDG_RUNTIME_DIR` 是否存在而变化：优先固定使用当前 UID 的私有 `/run/user/<uid>`，否则回退到经过所有者、符号链接和 `0700` 权限校验的 `/tmp/hyperhub-<uid>`，避免 `stop/status/run` 在不同 shell 中找不到同一个 Serve，也不会再修改共享 `/tmp` 的权限。

# Windows Run 退出后恢复终端

- `run` 不再只在启动目标前恢复控制台模式；`ssh`、`cmd` 等交互目标退出后会再次恢复 HyperHub 启动前的输入与输出模式。
- 正常退出、启动失败和异常展开均由同一保护器兜底，避免外层 PowerShell 将残留控制键解释为续行并反复显示 `More?`。

# HTTP 凭证清理客户端认证头

- 自动令牌允许同时配置自定义 Header；空值凭证 Header 表示删除客户端同名头，不再向上游发送空值。
- 请求先清理删除规则及即将覆盖的旧 Header，再注入非空自定义 Header 和可信 Bearer/Basic，避免 `glab api` 自带的无效 `Authorization` 或 `PRIVATE-TOKEN` 抢先触发 GitLab 拒绝。
- TUI 新建 HTTP 凭证默认添加空 `PRIVATE-TOKEN` 删除规则，并支持添加、修改或删除其他 Header；已有配置保持原样，可手工添加规则。
