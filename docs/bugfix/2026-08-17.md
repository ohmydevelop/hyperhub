# 2026-08-17

## SSH MITM PTY 大输出卡死

- 原因：MITM 同时使用 russh 的 channel 接收队列和 Handler 数据回调，却没有持续消费 channel 接收队列；大输出填满该有界队列后，russh 会话循环阻塞。此前再套一层每通道无界 `mpsc` 转发队列只会把压力搬到进程内存，调大 `event_buffer_size`/`channel_buffer_size` 也只能延后故障，不能建立端到端背压。
- 修复：上下行数据直接消费 russh `ChannelReadHalf`，通过受 SSH window 限制的 `ChannelWriteHalf::data_bytes` 转发；队列固定为 64 项，慢消费者会把背压传回上游，不再复制到无界应用队列。通道任一方向结束时统一关闭两端并清理映射/命令缓冲；正常空闲会话不再使用 60 秒 inactivity 超时误杀。
- 控制与观察：PTY、exec、shell、env、window-change、subsystem、signal、EOF/close 等控制请求直接转发，响应控制消息与数据保持 SSH 原始顺序；命令审计使用 256 项有界旁路队列和 16 KiB 单命令上限，磁盘慢或异常长输入不会阻塞数据面或无限占用内存，丢弃量会记录为 `ssh_audit_dropped`。
- 影响：交互 shell、通用 exec/subsystem、信号中断和大输出命令恢复连续转发；慢终端只降低该通道吞吐，不再拖垮 HyperHub 进程。
- 验证：真实 russh client → MITM → russh server 回归链路在客户端暂停读取时让 16 MiB 上游生产者受背压，恢复后完整接收全部字节、退出状态、`SIGINT` 和 subsystem 响应；`cargo test -p hyperhub-core ssh_mitm::tests::`。

## SSH 事件审计与会话内容开关语义不一致

- 原因：凭证 MITM 会无条件记录 SSH 命令事件，导致关闭 SSH 审计后仍能看到命令；另一方面，原 `SSH 转录` 在透传链路捕获的是加密后的网络字节，而 MITM 解密后的通道内容反而没有落盘，开关名称与实际结果不一致。
- 修复：审计方案中的 `SSH 事件审计` 仅控制 `ssh_command`、`ssh_shell`、`ssh_subsystem` 和通道结束等结构化事件；`SSH 内容转录` 独立控制解密后通道上下行内容。未绑定 SSH 凭证时不再把密文保存为转录，并记录 `ssh_audit_requires_credential` 说明跳过原因。
- 数据面：解密内容通过每方向 32 项有界旁路队列写入，队列满、达到内容上限或写盘异常时停止该方向捕获，但不等待、不阻塞 SSH 转发；会话结束事件携带捕获路径、大小、完整性和摘要元数据。
- 配置：SSH 会话内容必须同时启用 SSH 协议，WebSocket 内容必须同时启用 WS 协议；TUI 在开启内容捕获时自动启用对应事件审计，关闭协议时同步关闭其内容捕获，避免产生不可执行的配置。
- 影响：关闭 SSH 事件审计后不再新增命令日志；仅开启事件审计时仍可按事件聚合分析但不保存会话正文；同时开启会话内容且路由绑定 SSH 凭证时，才保存有上限的明文上下行文件。历史日志与转录不改写、不删除。

## PowerShell 启动时 ServicePointManager 初始化失败

- 原因：`resolve_target` 使用 `std::fs::canonicalize` 返回 Windows `\\?\` 扩展路径，直接作为 `CreateProcessW` 的 exe 路径会让 Windows PowerShell/.NET 初始化失败。
- 修复：目标解析后剥离 `\\?\` 前缀，仅用普通绝对路径启动；自比较仍先规范化为普通路径。
- 影响：`hyperhub powershell` 可正常进入 shell。
- 验证：`cargo test --workspace`；`hyperhub powershell -NoProfile -Command echo` 返回 0。
## 交互式密码输入后终端输出重叠

- 原因：`rpassword` 读取密码后不输出换行，子进程横幅与父级提示符/已输入命令在同一行重叠，表现为输出混乱。
- 修复：密码输入成功后向 stderr 输出一个换行，确认密码流程同样处理。
- 影响：交互式启动 `powershell`/`serve` 等子进程时不再与密码提示重叠。
- 验证：`cargo test --workspace`；release 版 `hyperhub powershell -NoProfile -Command echo` 返回 0。
