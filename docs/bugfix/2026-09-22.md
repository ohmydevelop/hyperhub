# 2026-09-22

## CI 隔离实例测试缺少 CLI 可执行文件

- 现象：`cargo test --workspace --all-targets` 只生成带哈希的测试程序，后续多 Home 集成测试找不到 `target/debug/hyperhub`。
- 修复：Linux CI 在运行隔离实例测试前显式执行 `cargo build -p hyperhub --locked`。

## Linux Benchmark 仍读取旧 SSH 信任路径

- 现象：Schema v2 已将 SSH 主机密钥移动到 `gateway.trust.ssh_host_keys`，但 TOFU Benchmark 仍读取旧顶层字段，CI 报 `KeyError: ssh_host_keys`。
- 修复：Benchmark 断言切换到 Schema v2 信任路径。

## Linux Benchmark 的 Schema v2 沙盒规则缺少启用字段

- 现象：固定沙盒 fixture 沿用旧 Schema 的 `enabled` 默认值，Schema v2 严格文档要求规则显式提供该字段，导入时报 `missing field enabled`。
- 修复：所有文件和子进程沙盒 Benchmark 规则显式设置 `enabled = true`。
