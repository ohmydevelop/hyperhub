# 2026-08-18

## 根证书首页 Space 无法启停

- 原因：TUI「证书」首页的 Space 分发只覆盖 SSH 主机密钥，根证书条目没有进入 `toggle_selected`，按 Space 后仅提示“当前项目不是可切换选项”。
- 修复：`toggle_selected` 增加根证书分支，按索引切换 `root_certificates[index].enabled`；首页 Enter/e 仍进入证书详情查看指纹与证书信息。
- 验证：新增 `root_certificate_space_toggles_on_homepage_and_enter_opens_details` 回归测试；`cargo test -p hyperhub` 44 个测试通过。

## 热更新丢失托管审计路径

- 原因：`AuditPolicy.audit.log` 与 `audit.transcript_dir` 带 `skip_serializing`，TUI `push_live_update` 发送 JSON 后会省略这两个字段；`RuntimeState::apply` 把反序列化得到的 `None` 装入新快照，导致 HTTP/WS/Git/SSH 内容转录在热更新后静默停止。
- 修复：`RuntimeState::apply` 在新配置两个字段为 `None` 时沿用旧快照的托管审计路径；TOML/JSON 不导出语义保持不变。
- 验证：`cargo check -p hyperhub-core`、`cargo check -p hyperhub` 通过；新增 `runtime::tests::hot_update_preserves_managed_audit_paths`，并扩展 `control::tests::config_update_is_applied_only_with_valid_proof` 覆盖 `ControlRequest::UpdateConfig` 端到端路径；`cargo test -p hyperhub-core --lib` 127 个测试通过。

## TUI 审计编辑器 Space 无法切换新增开关

- 原因：`object_field_is_toggle` 的 `ObjectEditor::AuditProfile` 分支只覆盖字段 1-5、7、8，漏掉 6（Git 内容转录）、9（客户端上传）、10（服务端响应），按 Space 会提示“当前字段不是可切换选项”。
- 修复：该分支改为覆盖字段 `1..=10`，与 `edit_audit_field` 的可切换/循环字段保持一致。
- 验证：`cargo check -p hyperhub-core`、`cargo check -p hyperhub` 通过；新增 `space_toggles_new_audit_fields_without_uneditable_status` 回归测试；`cargo test -p hyperhub --bin hyperhub` 45 个测试通过。

## 环境变量短值整体隐藏且无法清空

- 原因：`mask_middle` 对 ≤8 字符的内联环境变量值直接整体掩码，列表看不出任何前缀或后缀；修改已存在环境变量时空输入被保留为“未修改”，没有清空语义。
- 修复：短值也保留首尾少量字符、中间用 `••••••` 掩码；环境变量值输入 `-` 时清空为内联空字符串，并在应用后标记配置 dirty，避免改动丢失。
- 验证：更新 `environment_value_preview_masks_middle_and_shows_empty`，新增 `environment_value_can_be_cleared_with_dash`；`cargo test -p hyperhub` 46 个测试通过。
