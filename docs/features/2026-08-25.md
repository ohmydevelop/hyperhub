# 远程 Linux 构建与安装

- 增加 `scripts/build-remote-linux.ps1`，从 Windows 归档指定的已提交 Git revision，并统一通过 `hyperhub.exe run scp/ssh` 上传到目标 Linux 主机执行原生构建。
- 增加受约束的远端 helper；编排器根据远端架构在本地校验并上传 Frida Gum/Core devkit，再复用 `scripts/build.sh` 构建内嵌 Agent 的单文件 CLI，不要求远端访问 GitHub。
- 默认安装到 `/bin/hyperhub`，随后比较构建产物与安装文件 SHA-256，并通过 `--help` 和 `doctor` 验证 `agent_runtime=embedded-verified`。
- 脚本不安装发行版软件包、不硬编码远端系统环境；远端必须预先提供通用 Rust、C、Clang/libclang 和归档工具链。临时目录使用随机名称并默认在退出时清理。

## Config TUI 沙盒与进程导航收口

- 沙盒子项调整为“网络 → 文件 → 子进程”，与中文标签宽度和阅读顺序保持一致；文件页移除旧占位状态遗留的灰色样式，并显示与其他可编辑沙盒页一致的快捷键。
- 进程分类移除独立“基础”子页，将筛选总开关、默认动作和完整路径正则规则统一放入“进程 / 规则”，交互和“沙盒 / 网络”保持一致。
- 同步更新面包屑、选择提示、帮助文本、沙盒概览顺序以及导航和编辑回归测试。

## 命名正则库与规则引用

- 新增进程、命令、文件和 HTTP 路径四类强类型命名正则库，Process、Route、Firewall 与 Sandbox 规则统一改为 `*_regex_ref` 引用。
- Serve 在策略和 Sandbox 快照编译时解析引用并继续向 Agent 下发实际表达式，不修改控制协议或 Agent ABI。
- Config TUI 新增置顶“正则”能力域、四类 CRUD、引用预览、类型化选择器、重命名联动和被引用删除保护；首次打开仍默认选中网关。
- 本次配置格式为破坏性变更：旧内联正则字段加载即报错，需要按 README 迁移表人工创建命名正则并替换引用。
