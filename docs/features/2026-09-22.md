# 2026-09-22

## 隔离运行实例

- 新增 `HYPERHUB_HOME`，一个目录即可选择独立的配置、审批队列、日志、审计、证书、Chat 资产和 Serve 控制面，无需修改系统 `HOME`。
- Unix 控制 socket 自动位于 `$HYPERHUB_HOME/runtime/control.sock`；Windows named pipe 由当前用户 SID 与 `HYPERHUB_HOME` 共同派生，不提供独立的用户覆盖项。
- SOCKS5 端口占用时从配置端口开始逐个递增寻找空闲端口；Session Bootstrap 始终返回实际监听地址。
- `status` 新增 `hyperhub_home`、`control_endpoint` 和实际 `socks_address`，便于区分并行实例。
- Agent Skill 和内容寻址的内嵌 Agent 缓存可安全共享；进程 Session、密码授权缓存、监听端口和所有可变状态均按实例隔离。
