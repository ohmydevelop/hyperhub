# 2026-09-22

## 隔离运行实例

- 新增 `HYPERHUB_HOME`，一个目录即可选择独立的配置、审批队列、日志、审计、证书、Chat 资产和 Serve 控制面，无需修改系统 `HOME`。
- Unix 控制 socket 自动位于 `$HYPERHUB_HOME/runtime/control.sock`；Windows named pipe 由当前用户 SID 与 `HYPERHUB_HOME` 共同派生。`HYPERHUB_CONTROL_ENDPOINT` 保留为高级显式覆盖项。
- SOCKS5 端口占用时从配置端口开始逐个递增寻找空闲端口；Session Bootstrap 始终返回实际监听地址。
- `status` 新增 `hyperhub_home`、`control_endpoint` 和实际 `socks_address`，便于区分并行实例。
- Agent Skill 和内容寻址的内嵌 Agent 缓存可安全共享；进程 Session、密码授权缓存、监听端口和所有可变状态均按实例隔离。

## 模型网关

- 新增本机模型网关配置域，默认监听 `127.0.0.1:18445`，通过独立 API Key 鉴权。
- 下游支持 OpenAI-compatible 的 `/v1/models`、`/v1/responses` 与 `/v1/chat/completions`。
- Provider 支持 OpenAI-compatible API 和 ChatGPT/Codex 订阅类型；ChatGPT 类型支持 PKCE 授权 URL、token 交换/刷新接口，以及 Codex backend API 地址和请求头适配。
- 模型映射支持“下游模型名称 → Provider → Provider 模型”，Provider 模型可通过 `/v1/models` 获取并在 TUI 中搜索选择，也可手工输入。
- Provider token、refresh token、API Key 纳入现有加密配置，redacted 配置与普通 TUI 列表不展示明文。
- TUI 新增“模型网关”分类，提供网关配置、Provider 编辑、模型映射和模型发现刷新。
