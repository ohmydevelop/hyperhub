# Feature

- 优化 HyperHub CLI Skill 的意图执行流程：先读取配置并自动完成可确定工作，明确“只记录”或“阻断”时不重复询问；安全效果未明确时才询问用户。
- 统一 Proposal 交付状态与审批边界：自动提交脱敏 Patch，明确区分 `proposal_submitted` 和 `approved_verified`，并在用户审批后才执行运行态验证。
- 补充 Provider 异常、低置信度及失败关闭策略的决策提示，减少无意的全量阻断和重复提交。
- 新增 Serve restart 的加密 Session 持久化与恢复：保留根进程、受管成员、token 和 Fake-IP 映射，恢复时校验进程身份与启动时间；显式 stop 会清理状态。
