# 移除正则与进程筛选，重设计 TUI 与沙盒规则

- 删除 `RegexCatalog`、`NamedRegex`、所有 `*_regex_ref`/`path_regex` 以及 `[process]` 筛选配置；Agent 对根进程和后代始终 hook，`DecideProcessHook` 恒返回 hook。
- 沙盒规则改为一条规则多个普通目标：网络 `targets + ports`，文件 `paths + operations`，子进程 `executables + command_lines`；匹配使用域名、IP/CIDR、路径精确/目录前缀、命令行子串，不再按父进程限定。
- 路由删除 `process_regex_ref`、`ip_cidrs` 和 `ports`，`targets` 仍支持域名、URL 路径、IP 和 CIDR。
- 控制协议保留 `process_policy_version` 等字段但默认 `0/None/default`；`compile_snapshot` 不再接收 executable 参数，Agent wire snapshot 携带普通列表。
- TUI 导航改为“进程、网关、沙盒、环境变量”；删除正则库与进程规则页；路由/网络/文件/子进程列表统一用 `a` 添加、`Enter/e` 修改、`d` 删除。
- 旧 `[regex]`、`[process]`、`*_regex_ref`、`path_regex`、路由 `ip_cidrs/ports` 等字段加载时明确报错，错误会指出所在规则及 `targets`/`paths`/`executables`/`command_lines` 等替代字段；不静默放大规则范围，也不做有损转换。
- 文档与示例同步：删除正则配置和 `process_regex_ref`，补充沙盒普通目标列表示例与旧字段报错/迁移说明。
- 验证：`cargo fmt --all -- --check` 通过；`cargo test --workspace --all-targets --locked` 全部通过（hyperhub 69、hyperhub-agent-core 17、hyperhub-core 146）；`.\scripts\build.ps1` 通过（Gum Agent release 43 个测试、嵌入校验与单文件 Windows 构建）。

# 沙盒规则改为内联绑定与正则子项

- 网络规则的目标与可选端口改为 `endpoints` 绑定项，避免两个独立列表产生交叉组合。
- 文件和子进程规则将 regex 子项直接列在父规则表单底部，支持 `a` 添加、`Space` 独立启停、`Enter/e` 编辑与 `d` 删除；不恢复全局命名正则库或父进程限定。
- 上一版的 `targets + ports`、`paths`、`executables + command_lines` 配置需人工迁移，加载时会指出对应的 `endpoints` 或 `patterns` 替代形式。

# 网关路由绑定目标与端口

- 路由使用独立的 `endpoints` 绑定目标与可选端口，在网关侧选择 upstream、凭证、审计和 deny；与 Agent 侧网络沙盒的防火墙 `endpoints` 互不复用。
- TUI 中添加或修改路由目标时，先输入域名/URL 路径/IP/CIDR，确认后继续输入与该目标绑定的端口；端口留空表示任意端口。

# 新配置不再预置用户路由

- 首次初始化不再自动生成 GitHub、GitLab、OpenAI Codex 或 Claude Code 路由；仅保留结构上的内置默认路由作为未匹配连接的兜底，用户路由全部按需手动创建。

# 域名目标改为显式通配

- 网关路由和 Agent 网络沙盒统一采用显式语义：普通域名仅匹配自身，`*.example.com` 匹配任意层级子域名但不匹配根域名。
- URL 路径目标同样支持最左侧 `*.`；其它位置的通配符以及通配 IP/CIDR 会明确报错。
- 防火墙快照保留通配标记并传递到 Agent，TUI 输入提示、归一化和配置文档同步更新。现有依赖普通域名隐式匹配子域的配置需人工添加 `*.` 目标。

# 协议感知令牌鉴权

- HTTP 凭证新增 `token`：普通 HTTP 请求生成 Bearer，识别为 Git Smart HTTP 或 Git LFS 时自动生成 Basic；用户名和令牌只保存一次。
- 凭证不再维护 URL 列表，应用层范围统一由引用凭证的路由 endpoint 决定。含点分段、反斜杠或歧义百分号编码的 URL 配置和请求会 fail-closed；LFS 外部对象地址未命中凭证路由时不会携带令牌。
- TUI 仅展示“令牌（自动）”、令牌用户名和掩码令牌。旧 `scoped_token`、`bearer_paths`、`git_http_paths` 加载时明确提示迁移到 `token` 和路由 endpoint。
- 服务只审计 `WWW-Authenticate` 的方案与 realm，不根据 Challenge 切换鉴权或重放请求。
