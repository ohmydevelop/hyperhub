# Feature 2026-10-10

## 使用 API Key 运行目标程序

- `hyperhub run --password-file` 现在只接受 Serve 生成的运行时 API Key，不再把该文件当作管理员密码，也不会使用 `HYPERHUB_CONFIG_PASSWORD` 作为目标进程认证凭据。
- `hyperhub start`/`serve` 在当前 Home 的 `runtime/api-key` 生成并保存权限受限的 API Key，也支持通过 `--api-key-file` 指定位置。
- 需要解密配置的管理员命令统一使用交互式输入或 `--admin-password-file`；运行目标程序的 Agent 只需 API Key。
- API Key 认证与管理员密码认证使用独立的会话认证路径；API Key 成功认证不会开启管理员密码的本地缓存授权。
- API Key 文件采用 `hhk_` 前缀和 32 字节随机值，Linux 下限制为用户可读写，管理员密码文件会被 API Key 校验明确拒绝。

验证：API Key/管理员密码单元回归、会话认证回归、CLI 参数回归；完整工作区测试中的网络监听测试受当前沙箱 `Operation not permitted` 限制，非网络测试通过。
