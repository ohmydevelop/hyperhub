## CLI 自动升级

- `hyperhub start` 每个实例每 12 小时检查一次 GitHub Releases；交互式终端发现新版本时显示升级提示，非交互环境只记录可升级状态。
- 新增无参数 `hyperhub upgrade`，立即检查最新版本；发现升级后优雅停止 Serve，校验发行包 SHA-256，替换 CLI，并在原实例运行时尝试恢复启动。
- Linux x86_64/aarch64 和 Windows x64 使用 GitHub Release 对应压缩包；不执行远程 Shell 安装脚本。
- 升级检查状态按 `HYPERHUB_HOME` 隔离保存；当前版本已是最新或用户选择跳过时不会重复提示。
