# 2026-09-21

## 配置 Schema v2

- `show`、脱敏视图和 export 统一使用 `schema_version: 2`，按 `gateway`、`sandbox`、`environment_variables` 组织配置。
- 网关配置拆分为代理、凭证、审计设置/Profile、路由和 TLS/SSH 信任；不再向用户暴露混合类型的 `plugins` 数组。
- 路由使用 `decision.action = allow|deny`，并分别引用 `credentials` 与 `audit_profiles`；沙盒网络、文件和子进程策略统一使用 `default_action`、`error_action` 和 `rules`。
- 凭证采用带 `type` 的严格联合类型，只序列化当前凭证类型需要的字段；时间与容量字段使用显式单位后缀。
- Config CLI 的 Patch、UUID 注入、审批语义、Skill 和黑盒 Benchmark 已切换到 Schema v2 路径。
- v0.2.0 是破坏性版本：旧配置、旧导出和旧脱敏视图不会自动迁移或覆盖，检测到时明确拒绝并要求重新创建配置。
