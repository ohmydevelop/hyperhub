# 2026-09-21

## 智能防护布局与规则绑定简化

- Config TUI 将“智能防护”改为独立顶级分类，排列在沙盒子项之后、环境变量之前；`Enter/e` 进入 Profile 编辑，`Space` 单独切换 Profile 的全局启用状态。
- 路由、默认路由及进程/文件/网络沙盒规则统一使用可选 `protection` 引用；不再显示或保存规则级 `protection_enabled`，未设置即关闭。
- 进程、文件和网络沙盒规则都可选择 Protection；首次绑定分别自动选择 `network_upload`、`sensitive_read`、`network_egress`，解绑时自动恢复 `none`。
- Profile 的全局 `enabled` 保留，可一次停用所有引用；旧 `protection_enabled` 字段不再兼容。
