# Feature 2026-10-13

## 管理员密码与运行 API Key 分层

- 管理员密码只用于配置创建或修改路径：`config`、`chat`、`approve`、`import`，以及旧配置首次迁移或 API Key 封套修复。
- `start`、`restart`、`serve`、`run`、`validate` 和 `export` 使用运行 API Key，不再在常规冷启动或校验时读取管理员密码。
- 配置仍只有一份。管理员密码派生的配置主密钥由 API Key 加密保存到 `runtime/config-key.bin`；Serve 用封套解锁已审批配置，避免维护第二份运行配置。
- 旧配置首次升级启动时使用一次管理员密码生成运行封套；后续启动仅使用 `runtime/api-key`。显式向 `start` 传管理员密码可重新封装，用于 API Key 轮换或封套修复。
- 运行中的 TLS/SSH 首次信任继续使用已解锁的配置密钥原子持久化，不需要长期保存管理员密码。
- 明文导出仍要求交互式 `EXPORT` 确认；加密导出默认使用运行 API Key，也可以通过 `--export-password-file` 设置独立备份密码。
