# Linux 静态无符号程序覆盖

- 增加不依赖目标符号、动态加载器或较新可选内核特性的 ptrace syscall supervisor，接管 x86_64/aarch64 静态 ELF。
- 按 DNS、网络请求、descriptor、文件、映射、进程创建/exec/wait 意图建立静态 hook manifest，并为每个点位记录 fixture 覆盖率。
- 修复 UDP socket 被当成 TCP connect 重定向的问题；解析常见 DNS A/AAAA 响应，将后续 SOCKS5 CONNECT 恢复为域名目标。
- 静态 socket 支持 RFC 1929、route、firewall 和连接审计；Serve 对 SOCKS 入口执行 firewall 防御性复核。
- Session bootstrap 携带 sandbox snapshot；静态后端覆盖 file read/write/create/delete/rename 和 process clone/fork/exec deny/observe，并上报真实 PID 审计。
- 静态后代在第一次受控意图前登记真实 PID，fork/exec 后共享原 Session。
- C 对抗 fixture 覆盖 manifest 全部必测点，Go/Rust fixture 覆盖常见运行时路径和 exec 后代。
- benchmark 默认加入 BusyBox、GitHub CLI、yq 和 x86_64 ripgrep，生成 native/HyperHub CSV、汇总和 Markdown 报告。
- 使用 251 MiB 静态 PIE Codex CLI 完成真实模型对话验证；实现不包含 Codex 名称、路径或特征码分支。
