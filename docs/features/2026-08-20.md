# Config TUI 能力域导航

- 将平铺分类改为始终展开的树形导航，按“网关”“沙盒”“环境变量”三个产品能力域组织。
- 网关概览汇总 Serve、模式、监听地址及代理、凭证、审计、路由和证书数量，原有配置页迁移到网关子项。
- 沙盒概览承载活跃注入进程观测，网络子项承载 Firewall 配置；文件子项为只读禁用占位，不引入文件 Hook 或配置字段。
- 使用稳定导航节点枚举驱动导航、搜索、面包屑、提示与快捷键，避免依赖平铺分类下标。

## Agent 能力域边界解耦

- 将 Agent Core 拆分为 ABI、Control、Runtime、Gateway、Sandbox 与 Lifecycle 模块，公共 C ABI 和版本保持不变。
- 将 Windows Gum 拆分为 Gum 基础设施、HookManager、网络/信任/进程 adapter、类型化 runtime，以及 Gateway/Sandbox/Lifecycle capability。
- Gateway 聚合网络重定向与 CA 信任，Sandbox 聚合 Firewall，ChildProcess 保持独立 Lifecycle 能力；保留原插件 ID 和注册顺序。
- 网络 Context 不再暴露 `SOCKADDR` 指针或 original 参数，插件只声明有效目标和握手意图，由 adapter 编码地址并调用原函数。
- capability 使用显式依赖且不访问 original 槽位，为未来文件沙盒保留独立能力目录但不创建虚假 Hook。
