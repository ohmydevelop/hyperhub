# 2026-09-19

## 内嵌 Needle 3 本地配置 Chat

- 新增 `hyperhub chat`：输入 HyperHub 主密码后进入单列对话界面，布局采用顶部会话标识、中央消息流、底部圆角输入框和快捷键状态栏。支持 Unicode、中间编辑、粘贴、`Enter` 发送、`Ctrl+J` 换行和 `Ctrl+C` 退出。
- 将固定版本的 Needle 3 权重与对应平台 runner 嵌入 HyperHub 单文件程序。模型只在本机回环地址运行，显式关闭 Needle telemetry；用户输入、模型结果和敏感配置不发送到远端，也不会写入聊天记录。
- Chat 暴露语义化配置工具，覆盖运行模式、监听、审计、环境变量、HTTP 凭证、路由、上游代理、网络防火墙、文件沙盒和子进程沙盒。每轮只向 Needle 暴露与当前意图匹配的最小工具集合，明确区分“使用凭证的路由”和“新增凭证”；模型调用先在配置副本上执行，整批校验成功后才原子加密保存。
- Chat 已由用户输入主密码解锁活动配置，因此配置工具直接复用现有加密保存和 Serve 热更新通道，不创建审批队列，也不要求再次执行 `approve`。工具结果和界面摘要不回显凭证值。
- 构建阶段从固定 Hugging Face revision 获取模型和平台 runner，校验 SHA-256 后嵌入。当前官方制品覆盖 Linux x86_64/aarch64、Windows x86_64 和 macOS arm64。
- 回归覆盖命令解析、Codex 风格单列布局、Unicode 输入编辑、UUID 保持、凭证与认证路由组合校验，以及真实内嵌 Needle 3 推理后直接加密写入配置。
