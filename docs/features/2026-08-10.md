# 2026-08-10

## 加密配置与进程生命周期 Session

- 默认配置改为 `~/.hyperhub/config.bin`，使用 Argon2id、HKDF-SHA256 和 XChaCha20-Poly1305 加密，保存时原子替换并限制为当前用户访问。
- 新增 `hyperhub hyperhub serve config` Ratatui 配置界面，支持校验、密码修改、搜索和完整对象表单增删改；加密 BIN、明文 BIN、TOML 由独立的 `serve import/export` 命令处理。
- 首次初始化在主密码确认后立即生成并加密保存可运行的基础配置，预置 `127.0.0.1:18444`、当前平台控制端点、60 秒 pending Session 时间、enforce 模式和连接审计开关；无需先手工创建监听配置。
- Session 申请支持自动父进程鉴权与密码鉴权：Windows Serve 从 Named Pipe 获取真实客户端 PID，向上核验活动 Session 成员及进程路径，命中后直接签发 pending Session；否则回退到现有一次性 challenge-response。两种结果均使用同一 bootstrap、激活和根进程生命周期流程。
- Windows 子进程递归 Hook 扩展到 `CreateProcessInternalA/W` 与 `NtCreateUserProcess`。原生创建路径强制挂起子线程，缺少环境 bootstrap 时由子 Agent 通过 Named Pipe 的真实 PID 和父 Session 自动继承，再完成进程路径登记、Hook Ready 与恢复；enforce 下失败子进程不会运行。
- Session 改用单次 challenge-response 认证。Pending bootstrap 默认 60 秒；绑定根进程后不再使用时间 TTL，根进程退出即撤销 Session 和活动连接。
- Windows Agent 拦截 `CreateProcessA/W`，合并 Session 环境、挂起并注入后代进程，向 Serve 校验父子关系后恢复原始挂起语义。
- SOCKS5 RFC 1929 用户名升级为 `hh2:<session-id>:<pid>:<connection-id>`；控制 Named Pipe 和配置文件均限制为当前 Windows 用户。
- 凭证 TUI 改为类型驱动表单：HTTP 可选择 Bearer、X-API-Key 或仅自定义 Header，SSH 可选择密码或私钥；切换类型时只保留适用字段。Secret 和 Header 值直接加密保存，不再向用户提供环境变量输入语法。
- HTTP 凭证扩展为 Basic、Bearer、X-API-Key、Cookie、Query 参数和自定义 Header 六种一等类型。Basic 自动编码用户名与密码；Cookie 合并并替换同名项；Query 参数进行百分号编码并替换同名项，审计只记录注入名称而不记录值。
- Headers 从单次输入改为独立可滚动列表，以 `Key: ••••••` 展示且不限制数量；支持键盘添加、修改选中值和直接删除，不再使用隐藏的 `-Name` 删除语法。
- 新建配置默认将审计日志与转录写到 `~/.hyperhub/audit/`。审计模板使用“内容审计”总开关；关闭时隐藏正文上限、SSH 转录和 WebSocket 三项，并同步关闭对应捕获能力。
- 路由 TUI 收敛为多目标、进程、端口、协议、动作和对象关联：目标通过独立滚动列表逐项增删改并自动识别域名、IP、CIDR；Web 同时覆盖 HTTP/HTTPS；代理、凭证、审计使用带脱敏预览的选择框。新配置预置 GitHub、GitLab、OpenAI Codex、Claude Code 目标路由，不预置任何 Secret 或对象关联。
- 新增加密环境变量列表。Serve 在 Session bootstrap 时解析并下发变量，CLI 注入根目标进程；Agent 通过受保护的变量名清单将其合并到后代进程及自定义环境块。TUI 和日志均不显示变量值，并禁止覆盖 `HYPERHUB_*` 内部变量。
